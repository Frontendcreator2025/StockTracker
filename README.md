# Stock Analysis Dashboard 📈💹

## Descripción General

**Stock Analysis Dashboard** es una aplicación web desarrollada con **Streamlit** para el análisis financiero y la visualización de datos bursátiles.

La plataforma permite consultar y analizar el comportamiento de acciones utilizando información en tiempo real obtenida desde Yahoo Finance. Los usuarios pueden explorar métricas clave del mercado, visualizar gráficos interactivos y aplicar indicadores técnicos para apoyar la toma de decisiones basada en datos.

El proyecto combina análisis financiero, visualización de datos y desarrollo Python en una interfaz intuitiva y fácil de utilizar.

# 🏗 Arquitectura del Sistema

## Frontend

- Aplicación web desarrollada con Streamlit
- Diseño de pantalla amplia (Wide Layout)

- Componentes dinámicos para exploración de datos

## Visualización de Datos

La aplicación utiliza Plotly para generar visualizaciones interactivas como:

- Gráficos de velas (Candlestick)
- Gráficos de líneas
- Comparativas históricas
- Subplots financieros
- Visualización de volumen de operaciones

## Procesamiento de Datos

Los datos financieros son obtenidos mediante:
